# Image sources

All images are illustrative and are not presented as IsarKlima staff, completed installations, or project references. The website deliberately uses only images without visible faces.

## Generated imagery in active use

These project-specific images were created with OpenAI's built-in image generation on 27 August 2026. The original PNG files are stored in `assets/generated/`; responsive WebP variants are produced with `npm run images:generated`. Exact prompts are preserved in [generated-image-prompts.md](generated-image-prompts.md).

| Image family | Purpose |
| --- | --- |
| `hero-installation-detail` | Home and contact hero imagery |
| `commercial-installation-detail` | Commercial installation and process imagery |
| `technical-planning-workbench` | Planning, sizing and about-page imagery |
| `outdoor-unit-installation-detail` | Retrofit, outdoor-unit and location imagery |
